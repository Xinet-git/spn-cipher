# Учебный SPN: ECB и CBC

Реализация учебного блочного шифра SPN на Python. Шифрует текст и файлы, поддерживает режимы ECB и CBC. Проект использует только стандартную библиотеку Python; установка зависимостей не нужна.

> **Не используйте этот шифр для защиты реальных данных.** Это учебная конструкция, а не AES и не проверенный криптографический алгоритм. HMAC-SHA256 здесь выводит раундовые ключи, но **не** удостоверяет шифртекст. CBC допускает изменение данных без надёжного обнаружения; ECB раскрывает повторяющиеся блоки.

## Запуск

Требуется Python 3.9 или новее.

```bash
python spn_ecb_cbc_iso7816.py
```

Выберите шифрование или расшифрование текста либо файла, затем режим `ECB`/`CBC` и 16-байтовый ключ в hex (ровно 32 шестнадцатеричных символа). Для расшифрования укажите тот же ключ и режим. Например, учебный ключ `00112233445566778899aabbccddeeff` можно использовать только для демонстрации.

При работе с файлами укажите разные пути для входа и выхода. Программа целиком читает файл в память, поэтому не рассчитана на большие файлы. Текстовый шифртекст отображается в hex; для файлов записываются исходные байты результата.

## Как работает схема

- Размер блока: 128 бит; ключ: 128 бит; раундов: 8.
- Раунд: XOR с раундовым ключом, замена каждого байта через AES S-box, затем перестановка 128 бит (P-box). В восьмом раунде P-box пропускается, после чего выполняется финальный XOR.
- Девять раундовых ключей получаются из исходного ключа через HMAC-SHA256 с разными метками раунда. Это вывод ключей, а не проверка целостности сообщения.
- Дополнение: байт `80`, затем нулевые байты до границы блока, включая полный блок для уже кратных 16 байтам данных. Это байтовый вариант метода 2 ISO/IEC 9797-1.
- ECB шифрует блоки независимо. CBC использует случайный 16-байтовый IV; результат имеет формат `IV || ciphertext`. IV хранится открыто в начале результата.

S-box взят из FIPS 197, режимы соответствуют общему принципу ECB/CBC из NIST SP 800-38A, но сама конструкция SPN является учебной. Формат **не совместим** с более ранним `spn_cipher.py` (другая P-box, дополнение и формат контейнера) и с вариантом `spn_ecb_cbc.py`, который использовал PKCS#7.

## Использование как модуля

```python
from spn_ecb_cbc_iso7816 import encrypt, decrypt

key = bytes.fromhex("00112233445566778899aabbccddeeff")
ciphertext = encrypt("Пример".encode("utf-8"), key, mode="CBC")
plaintext = decrypt(ciphertext, key, mode="CBC").decode("utf-8")
print(plaintext)
```
